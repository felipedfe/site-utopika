# GIFs originais dos thumbs

Thumbs animados da página de projetos, guardados aqui quando foram trocados por vídeo (`thumb.mp4`) para deixar a página mais leve. Esta pasta não é publicada no site.

Para voltar um thumb para GIF:

1. Copiar `<projeto>.gif` daqui para `public/images/projects/<projeto>/thumb.gif`
2. Em `src/data/projects/index.js`, trocar o `images.thumbnail` do projeto para `'thumb.gif'`
